# Phase 2: UI Design Contract

> Visual and interaction contract for Phase 2 (`Offline SQLite Catalog, Sync Engine & Health Header`) of Apps Toko Rejeki Mobile. Generated by gsd-ui-researcher, preserving strict Velocity Blue parity with Phase 1 (`01-UI-SPEC.md` and `src/theme/tokens.ts`).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual Velocity Blue design system via `StyleSheet.create` + `src/theme/tokens.ts`) |
| Preset | not applicable (Expo React Native project, locked light mode via `userInterfaceStyle: "light"`) |
| Component library | none (React Native core primitives + Expo Router `Tabs`/`Stack` + `src/components/ui/VelocityPrimitives.tsx`) |
| Icon library | `lucide-react-native` (`^1.75.0`) + `react-native-svg` (`15.16.0`), verified against installed package types |
| Font | `@expo-google-fonts/hanken-grotesk` (`600`), `@expo-google-fonts/inter` (`400`, `600`), `@expo-google-fonts/jetbrains-mono` (`400`, `600`) |

**Design Direction & Antislop Dials (`Apps_Toko_Rejeki/design.md` & `01-UI-SPEC.md`):**
- **Identity:** Clean Enterprise POS ("Velocity Blue"), calibrated for fast counter scanning under bright retail lighting.
- **Dials:** `ENERGY 1` (calm operational clarity, zero visual clutter), `RHYTHM 2` (structured contrast between compact header status sub-bar, non-blocking sync banners, and stacked Pengaturan telemetry/audit cards), `MOTION 1` (purposeful press feedback `opacity: 0.85` / `scale(0.99)` and active-only sync icon rotation respecting OS Reduce Motion; zero endless idle pulse or bounce loops).
- **Light-mode lock:** Fixed light surfaces (`#f9f9ff` canvas, `#ffffff` cards) matching `Apps_Toko_Rejeki`.

## Spacing Scale

Declared values (multiples of 4 only, aligned with `TOKENS.spacing` in `src/theme/tokens.ts`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap inside status pills, metric label-to-value gap, audit row line spacing |
| sm | 8px | Gap between adjacent header pills, button row gaps, compact banner vertical padding, header sub-bar gap |
| md | 16px | Screen horizontal gutter (`16px`), card internal stack gap, `savedUrlBox` and telemetry box padding |
| lg | 24px | `SurfaceCard` and `ResetCacheConfirmModal` internal padding, scroll bottom clearance |
| xl | 32px | Modal icon badge (`32x32px`), major vertical breathing space |
| 2xl | 48px | Minimum touch target height (`48px`) across primary/secondary buttons, inputs, hint chips, and modal actions |
| 3xl | 64px | Bottom Navigation Bar base height (`64px` + bottom safe area) |

Exceptions: Primary buttons, inputs, collapsible triggers, hint chips, and modal actions enforce `48px` (`2xl`) `minHeight`. Compact header status pills in `TabScreenHeader` render with `8px` (`sm`) vertical and horizontal padding (`~34px` visual height) plus `hitSlop={{ top: 8, bottom: 8, left: 4, right: 4 }}` (`sm` / `xs`, both multiples of 4) to achieve a `50px` (`>= 48px`) effective vertical touch target while keeping header chrome compact on `360px` viewports, separated by `8px` (`sm`) minimum gap. All card, header, chip, metric tile, and audit row spacings strictly use declared `TOKENS.spacing` values (`4, 8, 16, 24, 32, 48, 64`).

## Visual Hierarchy & Component Contracts

### 1. Global Health & Sync Status Sub-Bar (`TabScreenHeader.tsx`, `NAV-03`, `D-03`..`D-05`)
- **Structure inside `TabScreenHeader`:**
  1. `headerRow`: `24px` screen icon (`#00478d`) + `20px` Heading (`Hanken Grotesk` 600 `#191c21`, `numberOfLines={1}`) + optional `rightSlot`, padding `16px` (`md`) horizontal & top, `8px` (`sm`) bottom (or `16px` bottom when `showStatusBar={false}`).
  2. `statusSubRow` (rendered on all 4 tabs `Kasir`, `Produk`, `Pesanan`, `Pengaturan` unless `showStatusBar={false}`): `paddingHorizontal: 16px` (`md`), `paddingBottom: 16px` (`md`), `flexDirection: "row"`, `flexWrap: "wrap"`, `alignItems: "center"`, `gap: 8px` (`sm`).
- **Pill 1 (`db-health-pill`) and Pill 2 (`sync-status-pill`):**
  - Visual box: `borderRadius: 8px` (`TOKENS.radii.sm`), `borderWidth: 1`, `paddingHorizontal: 8px` (`sm`), `paddingVertical: 8px` (`sm`), `flexDirection: "row"`, `alignItems: "center"`, `gap: 4px` (`xs`), `flexShrink: 1`, `maxWidth: "100%"`, `hitSlop={{ top: 8, bottom: 8, left: 4, right: 4 }}` (`50px` effective vertical target).
  - Text inside each pill: `Inter` 600, `13px`, `lineHeight: 18px`, `numberOfLines={1}`, `ellipsizeMode="tail"`. `Memeriksa...` pill strictly uses `#424752` (`onSurfaceVariant`, 8.42:1 on `#f2f3fb`) for text and `RefreshCw` icon.
  - **Icons (`14px`, matching label text color):**
    - DB Health Pill: `Server` (`LAN Online`), `Cloud` (`Cloud Online`), `ShieldAlert` (`Standby Baca Saja`), `CloudOff` (`Offline`), `RefreshCw` (`Memeriksa...`).
    - Sync Status Pill: `CheckCircle2` (`Katalog Siap`), `RefreshCw` (`Sync Penuh...` / `Sync Delta...`), `WifiOff` (`Mode Offline`), `AlertCircle` (`Sync Error`).
  - **Interaction & Anti-Flicker Rules (`D-05`, `R-19`):**
    - Tapping `db-health-pill` calls `refreshHealth()` (runs fast ~2s LAN probe with automatic Cloud fallback) and shows `Memeriksa...` during manual refresh; 10-second background health polls update state silently without flashing `Memeriksa...`.
    - Tapping `sync-status-pill` triggers `triggerManualDeltaSync("HEADER_BADGE_CLICK")` when `!isSyncing`. Routine 5-second `POLL_5S` cycles with `has_changes === false` keep `"Katalog Siap"` steady without strobing blue every 5 seconds; `"Sync Delta..."` displays during manual syncs, reconnection syncs, or active delta writes.
    - Icon rotation during active manual check / active sync uses Reanimated or Animated loop ONLY while `isSyncing || isManualRefreshing` is true AND `ReduceMotion` is disabled; zero infinite idle pulsing on `Offline` or `Sync Error`.
  - **Accessibility:** Both pills use `accessibilityRole="button"`, `accessibilityState={{ busy, disabled }}`, and explicit Indonesian `accessibilityLabel` naming state + tap action (e.g., `"Status database: Cloud Online. Ketuk untuk periksa ulang jalur LAN atau Cloud."`).

- **Expanded Panel (`16px` vertical gap, `maxWidth: 440` compatible on Login and full-width inside Pengaturan):**
  1. **Failover Note Box (`#f2f3fb`, `1px #e2e8f0`, `8px` radius, `8px` padding):** `"Smart Auto: coba LAN Utama dulu (~2 dtk), otomatis pindah ke Cloud Cadangan bila timeout tanpa memutus sesi."` (`13px` `Inter` 400 `#424752`).

     - Quick-fill chips row below Input 1 (`flexWrap: "wrap"`, `gap: 8`, each chip `minHeight: 48`, `maxWidth: "100%"`, `paddingHorizontal: 16px` (`md`), `#f2f3fb` fill, `1px #e2e8f0` border, `8px` radius, text `flexShrink: 1`):

  3. **Input 2 (`server-cloud-input`):** Label `"URL Cadangan (Cloud)"`, `InputField` (`minHeight: 48`, `monospace`, `keyboardType="url"`, placeholder `"https://kasir.tokorejeki.my.id"`, helper `"Jalur HTTPS otomatis saat di luar Wi-Fi toko."`).

       - `Cloud (kasir.tokorejeki.my.id)` -> populates Input 2

### 3. Initial Full Sync Banner, Empty State & Populated Shell (`InitialSyncBanner.tsx` + tab screens, `D-10`, `SYNC-02`)
- **Non-blocking Initial Sync Progress Banner:**
  - Mounted directly below `TabScreenHeader` (inside the 4 tab screens' top area, never overlapping `SafeAreaView` top inset) ONLY while `lastFullSyncAt === null && totalCachedProducts === 0 && isSyncing`.
  - Uses Velocity Blue info styling (`#d6e3ff` fill, `1px #00478d` border, `8px` radius, `16px` (`md`) horizontal / `8px` (`sm`) vertical padding, `16px` outer horizontal margin):
    - Leading `ActivityIndicator size="small" color="#00468c"` + Title `"Menyinkronkan katalog toko..."` (`13px` `Inter` 600 `#00468c`) + Subtitle `"Mengunduh produk, kategori, dan satuan. Navigasi tetap dapat digunakan."` (`13px` `Inter` 400 `#00468c`).
- **Initial Failure vs Legitimate Empty `Kasir Mini` vs Populated Phase 2 Shell (`D-10`, `D-12`):**
  - **Initial Failure (`lastFullSyncAt === null && totalCachedProducts === 0 && !isSyncing`):**
    - `EmptyStateCard` on `Kasir` / `Produk` displays `CloudOff` (`24px` `#93000a` inside `#ffdad6` icon box), heading `"Katalog Lokal Belum Tersinkron"`, guidance body, primary `#00478d` `PrimaryButton` (`minHeight: 48`): `"Sinkronkan Sekarang"` (loading: `"Menyinkronkan..."`), and `SecondaryButton variant="tonal"` (`minHeight: 48`): `"Buka Pengaturan"` -> navigates to `/pengaturan`, plus automatic retry once `SystemStatus` detects connectivity recovery.

    - `EmptyStateCard` displays `Database` (`24px` `#00478d` inside `#ecedf6` icon box), heading `"Katalog Kasir Mini Masih Kosong"`, role-safe body stating sync succeeded with 0 active items, and `SecondaryButton variant="outlined"` (`minHeight: 48`): `"Sinkronkan Sekarang"`.

    - `InitialSyncBanner` unmounts cleanly. `Kasir`, `Produk`, and `Pesanan` retain their Phase 1 operational/policy cards (`Mode Baca Saja (Kasir)` vs `Mode Kelola Katalog Aktif`, plus read-only synced catalog count note) until Phases 3–4 deliver full POS and product list/detail screens.
