# Phase 1: UI Design Contract

> Visual and interaction contract for Phase 1 (`Auth, LAN Transport Spike & Role-Protected Shell`) of Apps Toko Rejeki Mobile. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual Velocity Blue design system via `StyleSheet.create` + `src/theme/tokens.ts`) |
| Preset | not applicable (Expo React Native project, forced light theme per `Apps_Toko_Rejeki/apps/src/app/globals.css`) |
| Component library | none (React Native core primitives + Expo Router `Tabs` & `Stack` + typed Velocity Blue primitives) |
| Icon library | `lucide-react-native` (`^1.74.0`) + `react-native-svg` (`15.16.0`), matching web `lucide-react` 1:1 |
| Font | `@expo-google-fonts/hanken-grotesk` (`600`), `@expo-google-fonts/inter` (`400`, `600`), `@expo-google-fonts/jetbrains-mono` (`400`, `600`) |

**Design Direction & Antislop Dials (`Apps_Toko_Rejeki/design.md`):**
- **Identity:** Clean Enterprise POS ("Velocity Blue"), calibrated for high-speed retail counter legibility under bright store lighting.
- **Dials:** `ENERGY 1` (calm authoritative retail shell), `RHYTHM 2` (structured contrast between Login focal card, stacked Settings cards, and role-aware Tab placeholders), `MOTION 1` (purposeful press feedback `activeOpacity`/`scale(0.99)` and accordion expand/collapse only; respect OS Reduce Motion; zero endless loops or decorative glows).
- **Light-mode lock:** `app.config.ts` sets `userInterfaceStyle: "light"` to match web `color-scheme: light`.

## Spacing Scale

Declared values (multiples of 4 only, matching standard 8-point grid and `design.md`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon-to-badge gaps, field label to input gap (`4px`), helper text top margin |
| sm | 8px | Adjacent button/chip spacing, inline icon-to-text gap (`8px`), compact banner vertical padding |
| md | 16px | Screen horizontal gutter (`16px`), form field stack gap, standard card gap (`16px`) |
| lg | 24px | Login card and modal internal padding (`24px`), vertical section spacing (`24px`) |
| xl | 32px | Major screen top/bottom scroll breathing space (`32px`) |
| 2xl | 48px | Minimum touch target size (`48px x 48px`), button height, input height, profile avatar box |
| 3xl | 64px | Login store logo/monogram box (`64px x 64px`), Bottom Navigation Bar base height (`64px` + bottom safe area) |

Exceptions: Minimum interactive touch target is `48px x 48px` (`2xl`) across all buttons, icon-only toggles (password visibility eye icon), and collapsible headers per `design.md` (`touch-target: 48px`) to maintain thumb accuracy at busy checkout counters. Structural borders (`1px` resting, `2px` focus ring) are stroke widths rather than layout spacing.

## Visual Hierarchy & Screen Contracts

### 1. Root Auth & Role-Protected Stack (`app/_layout.tsx`)
- **Boot gate:** Hold `expo-splash-screen` via `SplashScreen.preventAutoHideAsync()` until Google Fonts (`Hanken Grotesk`, `Inter`, `JetBrains Mono`), `expo-secure-store` (`pos_session` + `auth_user_snapshot`), and `expo-sqlite/kv-store` (`server_base_url` + `pos_store_settings`) finish loading. Zero flash of unstyled or unauthenticated UI.
- **Stack guards (`NAV-04`, `D-07`):**
  - `<Stack.Protected guard={!user}>` mounts `(auth)/login`.
  - `<Stack.Protected guard={Boolean(user)}>` mounts `(tabs)` with key `user.id + ":" + user.role` so account switches discard prior screen history cleanly.
- **Online session revalidation (`D-04`, `AUTH-03`):**
  - Call `GET /api/auth/me` once on mount when network is available.
  - Clear `pos_session` and `auth_user_snapshot` ONLY on HTTP `401` or `403` (redirect to `/(auth)/login` with error banner `"Sesi tidak valid atau akun dinonaktifkan. Silakan masuk kembali."`).
  - Retain `auth_user_snapshot` on `500`, `503`, timeouts, or offline launches so authenticated staff enter the 4-tab shell immediately.

### 2. Login & Collapsible Server URL (`app/(auth)/login.tsx`)
- **Primary visual anchor:** Single elevated white Login Card (`#ffffff`, `1px` `#e2e8f0` border, `16px` radius, `24px` padding, `maxWidth: 440` centered) on `#f9f9ff` canvas inside `KeyboardAvoidingView` + `ScrollView` (`keyboardShouldPersistTaps="handled"`). Eye flows vertically: `64x64px` Brand Badge (`TR` or `storeLogo`) -> Store Title (`24px`) -> Collapsible `Alamat Server API` -> Inline Feedback Banner -> `Username` -> `Kata Sandi` -> full-width `#00478d` `Masuk ke Sistem` CTA.
- **Brand badge (`D-06`):** `64x64px` rounded container (`16px` radius, `2px` `#00478d` border). Renders cached `storeLogo` (`Image` `resizeMode="cover"`, explicit `64x64` dimensions) when available, else solid `#005eb8` fill with white `TR` initials (`24px` Display SemiBold).
- **Collapsible `Alamat Server API` panel (`D-01`, `D-02`, `AUTH-02`):**
  - Collapsed header (`minHeight: 48`, `#f2f3fb` background, `1px` `#727783` border, `8px` radius, `16px` horizontal padding): `Server` icon (`16px`) + `"Alamat Server API"` (`13px` SemiBold) + truncated current URL (`JetBrains Mono` `13px`, `numberOfLines={1}`) + `ChevronDown`/`ChevronUp` (`16px`). Accessibility: `accessibilityRole="button"`, `accessibilityState={{ expanded }}`, `accessibilityLabel="Ubah alamat server API"`.
  - Auto-expanded on initial install when no `server_base_url` is saved; collapsed by default once configured.
  - Expanded body (`16px` vertical gap):
    - Visible label `"URL Server Toko"` + `48px` tall input (`JetBrains Mono` `16px`, `autoCapitalize="none"`, `autoCorrect={false}`, `keyboardType="url"`, placeholder `"http://192.168.1.10:3000"`).
    - Helper hint (`13px` `#424752`): `"Contoh LAN: http://192.168.1.10:3000 atau Emulator Android: http://10.0.2.2:3000"`.
    - Two-button row (`8px` gap): `"Tes Koneksi Server"` (`minHeight: 48`, outlined `#00478d` + `Wifi` icon) and `"Simpan Alamat Server"` (`minHeight: 48`, secondary filled `#ecedf6` with `#191c21` text).
    - Live test result banner (`CheckCircle2` green or `AlertCircle` red) updating store logo/name immediately on `GET /api/settings` `200`.
- **Login Inputs & Password Toggle (`AUTH-01`):**
  - `Username`: visible label `"Username"`, `48px` height, `#f2f3fb` resting fill (`#ffffff` + `2px` `#00478d` on focus), leading `User` icon (`16px`), placeholder `"Masukkan username..."`.
  - `Kata Sandi`: visible label `"Kata Sandi"`, `48px` height, leading `Lock` icon (`16px`), `secureTextEntry={!showPassword}`, trailing `48x48px` pressable toggle (`Eye` / `EyeOff` `16px`, `accessibilityRole="button"`, `accessibilityLabel={showPassword ? "Sembunyikan kata sandi" : "Tampilkan kata sandi"}`).
  - `429` countdown state: amber warning banner with `Clock` icon showing live 1-second decrement (`"Terlalu banyak percobaan gagal. Coba lagi dalam {N} detik."`), disabling `Masuk ke Sistem` until timer reaches `0`.

### 3. Bottom Navigation Bar (`app/(tabs)/_layout.tsx`)
- Rendered for ALL authenticated roles (`kasir`, `admin`, `owner`) via Expo Router `<Tabs>` (`NAV-01`, `D-08`).
- Surface: `#ffffff` fill, `1px` top border `#e2e8f0`, base height `64px` (`3xl`) + `insets.bottom`, zero floating blur.
- **Tab items (4 equal 25% columns, each `minHeight: 48`, icon + `13px` single-line label):**
  1. `kasir`: Label `"Kasir"`, Icon `Calculator`
  2. `produk`: Label `"Produk"`, Icon `Package`
  3. `pesanan`: Label `"Pesanan"`, Icon `ReceiptText` (no hardcoded fake badge number in Phase 1; dynamic badge wired in Phase 4)
  4. `pengaturan`: Label `"Pengaturan"`, Icon `Settings`
- **Active vs Inactive state (never color-only):** Active tab gets `#00478d` icon + `600` weight `#00478d` label + `#d6e3ff` rounded-square pill behind icon + `2px` top `#00478d` bar. Inactive tabs use `#525866` (`7.13:1` contrast) with `400` weight label.
- **Content clearance:** Every tab screen pads scroll bottom by at least `24px` (`lg`) inside the `<Tabs>` content container so controls never sit under the tab bar.

### 4. Role-Protected Tab Screens (`kasir`, `produk`, `pesanan`, `pengaturan`)
- **Top Screen Header (shared pattern):** `#ffffff` bar, `1px` bottom `#e2e8f0` divider, `16px` padding, `24px` tab icon (`#00478d`) + `20px` Heading (`Hanken Grotesk` 600 `#191c21`).
- **Tab `Kasir` (`kasir.tsx`):** Primary focal card shows active cashier greeting (`fullName`), role badge, and Phase 1 operational notice with working button `Buka Pengaturan Server`.
- **Tab `Produk` (`produk.tsx`, `NAV-04`):**
  - Primary top anchor depends on authenticated role:
    - **`kasir`:** Persistent amber policy banner (`#fef3c7`, `1px` `#f59e0b` border, `ShieldCheck` icon): heading `"Mode Baca Saja (Kasir)"` (`16px` SemiBold `#78350f`), body `"Akun Kasir hanya dapat melihat daftar produk dan harga jual. Harga modal dan aksi ubah produk disembunyikan."` (`13px` `#78350f`).
    - **`admin` / `owner`:** Velocity Blue policy pill (`#d6e3ff`, `#00468c` text, `ShieldCheck` icon): `"Mode Kelola Katalog Aktif"` indicating write permissions will unlock once catalog sync lands.
  - Below banner: Phase 1 empty-catalog card (`Katalog Produk Belum Tersinkronisasi`) with working CTA `Periksa Koneksi di Pengaturan`.
- **Tab `Pesanan` (`pesanan.tsx`):** Clean empty-state card (`Belum Ada Pesanan Tertunda`) with `ReceiptText` icon and working CTA `Ke Layar Kasir`.
- **Tab `Pengaturan` (`pengaturan.tsx`, `AUTH-02`, `AUTH-04`, `D-08`):**
  - **Primary visual anchor:** Active Account Profile Card (`#ffffff`, `1px` `#e2e8f0`, `16px` radius, `24px` padding): `48x48px` role-colored avatar (`Owner` `#7c3aed` `ShieldCheck`, `Admin` `#00478d` `ShieldCheck`, `Kasir` `#047857` `User`), `fullName` (`20px` Heading), `@username` (`13px` `JetBrains Mono` `#424752`), and role badge pill.
  - **Server Connection Card (`#ffffff`, `1px` `#e2e8f0`, `16px` radius, `24px` padding):** Displays saved `Alamat Server API` (`JetBrains Mono` `13px`, wraps cleanly up to 2 lines), session persistence status badge (`Sesi Lokal Aktif` green), plus inline collapsible editor and `Tes Koneksi Server` / `Simpan Alamat Server` buttons.
  - **Destructive Action Card:** Full-width `48px` tall button `Keluar dari Akun` (`#ffffff` fill, `1px` `#dc2626` border, `#dc2626` `LogOut` icon + text). Tapping opens the centered `Modal` (`rgba(25, 28, 33, 0.55)` backdrop, `onRequestClose` enabled) with `"Keluar dari Akun?"`, warning box, `Tetap Masuk`, and `Ya, Akhiri Sesi` (`#dc2626` fill, fail-safe offline clear + stack reset to `/(auth)/login`).

## UI Considerations

Applicable state considerations resolved (post-verification probe: 24 applicable across `E1`–`E4`, 0 unclassified):

### Resolved (Explicit — verifiable in component/unit tests)
- **E1 (`empty`, `partial`):** Unfilled `Username`/`Kata Sandi` submission displays `400` inline error banner (`Username dan kata sandi wajib diisi sebelum masuk.`) without calling `/api/auth/login`; absent `storeLogo` renders `TR` monogram badge (`64x64px`, `#005eb8` fill).
- **E1 (`loading`, `populated`):** Submitting login disables `Masuk ke Sistem`, shows loading label `Memeriksa Akses...`, and hides/shows password via `48x48px` `Eye`/`EyeOff` toggle; populated `storeInfo` renders cached/fetched logo and store name.
- **E1 (`error`):** `401`, `403`, `429` (live 1s decrement countdown disabling submit until `0`), and `503`/offline network failures render their respective Copywriting Contract error banners with recovery guidance.
- **E2 (`empty`, `partial`, `loading`, `error`):** Unconfigured `server_base_url` auto-expands `Alamat Server API` (`Alamat Server Belum Terhubung`); invalid URL or unreachable host shows inline error banner without overwriting valid saved URL; `Tes Koneksi Server` shows `Menguji Koneksi...` loading state and updates badge to `Server Terhubung` on `200`.
- **E3 (`loading`, `error`):** Native splash screen holds via `SplashScreen.preventAutoHideAsync()` until fonts, `SecureStore`, and `kv-store` hydrate; `401` or `/api/auth/me` `403` clears local session and routes to `/(auth)/login`, while `500`/`503`/offline retains snapshot and mounts `(tabs)`.
- **E4 (`empty`, `loading`, `error`, `populated`):** `Produk` (`Katalog Produk Belum Tersinkronisasi`) and `Pesanan` (`Belum Ada Pesanan Tertunda`) display Phase 1 empty-state cards with working navigation CTAs; `Produk` displays `Mode Baca Saja (Kasir)` for `kasir` and `Mode Kelola Katalog Aktif` for `admin`/`owner`; `Pengaturan` displays active user `fullName`, `@username`, role badge, saved Server URL, and `Keluar dari Akun` modal (`Ya, Akhiri Sesi` shows `Mengakhiri Sesi...` and clears session even if `/api/auth/logout` fails offline).

### Resolved (Backstop — visual / layout verification)
- `{ statement: "E1 long-text: Long store titles or error messages inside Login Card wrap cleanly inside maxWidth 440 without clipping or horizontal overflow.", verification: backstop }`
- `{ statement: "E2 overflow/long-text: Long LAN or HTTPS tunnel URLs truncate cleanly (`numberOfLines={1}`) in collapsed `Alamat Server API` header and scroll/wrap inside `URL Server Toko` input.", verification: backstop }`
- `{ statement: "E3 overflow/long-text: 4 equal 25%-width Bottom Navigation Bar tabs (`Kasir`, `Produk`, `Pesanan`, `Pengaturan`) fit single-line `13px` labels on 360px screens with `>= 24px` bottom content clearance.", verification: backstop }`
- `{ statement: "E4 overflow/long-text/partial: Long staff names, `@username`, and up to 2-line wrapped Server URLs inside `Pengaturan` cards and `Keluar dari Akun?` modal stay readable inside `ScrollView` bounds.", verification: backstop }`

### Dismissed (with reason)
- **E4 (`zero-one-many`):** Dismissed — Phase 1 `Produk` and `Pesanan` screens display static single-card Phase 1 placeholders only; dynamic multi-item list scaling (`zero/one/many`) enters scope in Phase 4.
